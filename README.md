# opo7

https://guccibum.github.io/opo/

```bash
python3 serve.py
```

The row at the top and three empty pages. Nothing else — what goes in them has
not been decided yet.

- `js/nav.js` — the row. Words are placed absolutely from widths measured on a
  canvas, the row starting a third of the way across, one space between words.
  Each word is an outer catch area that never moves and a label inside it that
  slides on hover.
- `js/main.js` — names the three pages and lands on the first.
